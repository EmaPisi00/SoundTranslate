# SoundToTranslate

Si tratta di un'applicazione sviluppata in Java, con interfaccia utente realizzata tramite la libreria JavaFX. L'applicativo integra un modulo Python, utilizzato per sfruttare modelli di traduzione automatica dall'inglese all'italiano. Inoltre, è integrata una libreria per la trascrizione automatica del contenuto audio, che consente di convertire il parlato in testo, rendendo l'applicazione particolarmente utile per scenari di sottotitolazione o supporto linguistico.
